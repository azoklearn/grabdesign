# Grab Design — contenu Chrome Web Store

## Nom

Grab Design

## Résumé (132 caractères maximum)

Sélectionnez un élément web et copiez son HTML + CSS fidèle, prêt à utiliser dans votre prochain projet.

## Description détaillée

Grab Design accélère l’étape entre l’inspiration et la construction.

Survolez un élément sur une page web, cliquez, puis récupérez immédiatement un fragment HTML avec les styles CSS utiles directement dans votre presse-papiers. Collez-le dans votre projet ou donnez-le à votre outil de création préféré.

### Ce que Grab Design fait

- Sélectionne l’élément visible que vous choisissez.
- Copie un fragment HTML et CSS compact, fidèle à l’état affiché.
- Conserve les ressources de l’élément sous forme d’URL absolues lorsque possible.
- Traite chaque sélection localement dans votre navigateur.

### Ce que Grab Design ne fait pas

- N’envoie pas vos sélections, votre navigation ou vos données à un serveur.
- N’exporte pas les scripts privés, les appels API ou les interactions d’un site tiers.
- Ne donne aucun droit sur les contenus, marques ou créations capturés : respectez les droits et conditions applicables.

### Permissions utilisées

- `activeTab` et `scripting` : activent le sélecteur uniquement dans l’onglet où vous venez de cliquer sur Grab Design.
- `clipboardWrite` et `offscreen` : copient le résultat de votre sélection dans votre presse-papiers.

## Déclaration Privacy Practices

- **Objectif unique :** permettre à l’utilisateur de sélectionner un élément visible d’une page et d’en copier localement un fragment HTML/CSS.
- **Données de site web :** traitées uniquement à la demande de l’utilisateur dans le cadre de l’élément qu’il sélectionne ; elles ne sont jamais transmises hors de son navigateur.
- **Vente ou transfert de données :** non.
- **Utilisation de données à des fins publicitaires :** non.
- **Politique de confidentialité :** publier l’URL `/privacy.html` de la landing page.
