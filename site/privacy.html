Ce que fait Grab Design

Grab Design sélectionne, à votre demande, l’élément d’une page web sur lequel vous cliquez. Il prépare un fragment HTML et des styles CSS utiles, puis les copie dans le presse-papiers de votre appareil.

Les données traitées

L’extension traite le contenu visible de l’élément que vous avez explicitement sélectionné : sa structure HTML, ses styles, et les ressources associées. Cela peut inclure du texte, des URL et, si vous sélectionnez un formulaire, les valeurs visibles de ce formulaire.

Où vont ces données

Grab Design ne possède pas de serveur de collecte et n’envoie aucune sélection, aucun code, aucune URL, ni donnée de navigation à Grab Design ou à un tiers. Le traitement et la copie se font localement dans Chrome, sur votre appareil.

Permissions Chrome

activeTab et scripting sont utilisés uniquement après votre clic pour activer le sélecteur dans l’onglet courant. clipboardWrite et offscreen servent à placer le résultat de votre sélection dans le presse-papiers. Aucune permission n’est utilisée pour surveiller votre navigation en arrière-plan.

Vos choix

Vous contrôlez chaque sélection. Évitez de copier des données confidentielles ou des formulaires contenant des identifiants. Vous pouvez supprimer l’extension à tout moment depuis Chrome ; Grab Design ne détient aucune donnée à supprimer.
